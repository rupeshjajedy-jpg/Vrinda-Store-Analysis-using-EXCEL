# 📊 Vrinda Store Analysis using Excel

## 📌 Problem Statement

Vrinda Store wants to create an annual sales report for **2022** to understand customers and improve sales in **2023**.

## 🛠️ Tools & Skills

* Microsoft Excel
* Data Cleaning
* Data Processing
* Data Analysis
* Pivot Tables
* Data Visualization

## 🔄 Project Steps

**Data Cleaning → Data Processing → Data Analysis → Data Visualization → Report → Insights**

## ❓ Key Questions

* Compare sales and orders using a single chart.
* Which month had the highest sales and orders?
* Who purchased more — men or women?
* What was the highest-selling category?
* What are the different order states?
* What is the relationship between age, gender and orders?

## 💡 Key Insights

* Women contributed approximately **65%** of purchases.
* **Maharashtra, Karnataka & Uttar Pradesh** were the top 3 states, contributing around **35%**.
* **30–49 years** age group contributed approximately **50%**.
* **Amazon, Flipkart & Myntra** were the major contributing channels.

## 🎯 Final Conclusion

Target **women aged 30–49 years** from **Maharashtra, Karnataka & Uttar Pradesh** through targeted **ads, offers and coupons** on **Amazon, Flipkart & Myntra** to increase sales.
